## Abstract
Bintrong game is a designed to be a free accessable game for students to study questions using competition. A key goal is take make the solution freeware so anyone can host it for free. The plan is for the game application to provide options for generating card packs via LLM. The intent behind this project is to encourage competition in order to trick users into studying. The game will be designed to be short review games based around some form of parkour or survival scenario. The player's objective will be to control his or her character and select the correct answer based on the game. Existing tooling is not self hostable and locks key features behind paywalls. Existing tools are often proprietary and require the user to work within their ecosystem. There are no existing Anki projects that follow a similar self-hostable tooling design. Other games that take advantage of Anki are less interactive and less fun. Having a public facing URL where a host can create a lobby that is code-locked is crucial for use with educators.
